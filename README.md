# 💰 Crypto Tracker – React Cryptocurrency Dashboard

A modern, responsive cryptocurrency tracking application built with **React.js**.  
This app displays live market data, coin prices, and detailed analytics using a public crypto API.

---

## 🚀 Features

- 📈 Real-time crypto price updates
- 🔍 Search and filter coins by name/symbol
- 🪙 Coin detail pages with graphs and stats
- 🌐 Currency conversion (USD, EUR, etc.)
- 📊 Charts with price trends over time
- 🌓 Light/Dark theme toggle (optional)
- ⚡ Fast and responsive UI

---

## 🛠️ Tech Stack

- **React.js**
- **Axios** – API requests
- **React Router** – Navigation
- **Chart.js / Recharts** – Graphs & data viz
- **Styled Components / SCSS** – Styling
- **Crypto API** – CoinGecko or similar
